# Changelog

## 0.3.0 — feature provenance, release polish, and inference safeguards

- Added a versioned feature registry and generated dictionary with exact units, OpenCV definitions and methodological limitations.
- Added an original synthetic SVG demonstration with recorded image-derived metrics, plus a determinism check.
- Added a mandatory explicit analysis gate separating structural correctness from lab-approved inference.
- Added seven synthetic tests covering the feature registry, analysis guard, and public visual demonstration.
- Expanded CI to verify documentation/demo reproducibility, and strengthened public-file screening.
- Improved the README and release handoff; historical notebooks and study results remain unchanged.

**Still blocked:** eight unadjudicated session mappings, absent approved mixed-gender feature verification and unexecuted historical R inferential analysis.


## 0.2.0 — research-engineering review

- Audited the earlier private image catalog and participant mapping, reporting 384 catalog entries, 190 participant rows, eight unresolved mapping statuses and mixed-gender coverage concerns.
- Built `avatar_vision.audit` for strict key and mapping checks and privacy-safe aggregate diagnostics.
- Added `avatar_vision.aggregate` to join first, second, third and final avatar evidence without imputing unavailable selections.
- Added `avatar_vision.features` for reproducible, explicitly pixel-derived image measurements and documented filename design labels.
- Added catalog measurement-range checks, synthetic tests and a synthetic end-to-end demonstration.
- Separated exploratory legacy Python/R notebooks from newly tested engineering utilities.
- Rewrote methods, evidence, reproducibility, dataset handling and publication limitations.

**Unchanged:** original research notebooks, R models and historic coefficients were preserved for provenance; they are not independently validated conclusions.
