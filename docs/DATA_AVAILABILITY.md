The user confirms permission to publish both ASU research projects' **source code**, excluding original datasets and model weights. This repository contains only code, tests using invented records, and aggregate descriptive audit results.

The private original archive includes participant-linked survey/session records and avatar artwork. It also includes a 384-name image-metrics catalog (192 female, 192 male) and a separate 192-row female-only automatic feature table. **None of those tables or images is redistributed here.** Permission to publish research source code does not itself establish permission to redistribute original images, participant data, or their derivative row-level outputs.

To reproduce the private study, obtain the lab-approved data, adjudicate unresolved session mappings and document the allowed uses. Keep raw data and derived participant-level outputs outside public GitHub; check consent/IRB rules when applicable. The source package does not include a general-purpose license or claim ownership of research collaborators' work.
